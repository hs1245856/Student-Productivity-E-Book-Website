# 📚 Productivity for University Students

A modern and responsive React-based website for the **Productivity for University Students** eBook. The website features an interactive book showcase, chapter previews, printable worksheets, productivity planners, cheat sheets, and a premium user experience.

## 🌐 Live Demo

**https://student-productivity-ebook-website.vercel.app/**

## ✨ Features

- 📖 Beautiful landing page with modern UI
- 🎨 Premium responsive design
- ⚡ Smooth animations and transitions
- 📚 Complete eBook showcase
- 📝 Chapter previews
- 📄 Free sample download
- 🗂️ Printable productivity worksheets
- 📊 Productivity planners and templates
- 🎯 Goal planning resources
- ⏱️ Pomodoro study planner
- 📅 Semester & weekly planning tools
- 🧠 Productivity cheat sheets
- 📱 Fully responsive for desktop, tablet, and mobile
- 🔍 SEO-friendly structure
- ⚡ Fast loading and optimized performance
- 💬 WhatsApp purchase integration
- 🌐 Social media integration
- 🎓 Designed specifically for university students
